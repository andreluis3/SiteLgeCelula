# LGE/IPT: cópia de trabalho (provisória)

Executar: `python3 -m http.server 8000` na pasta do projeto e abrir http://localhost:8000
(necessário servidor por causa dos módulos ES; abrir index.html direto via file:// não funciona).

- Textos e contatos: `src/data/content.js`
- Tokens visuais provisórios: topo de `src/css/styles.css`
- Pendências: `docs/pendencias.md`; auditoria: `docs/auditoria_site_oficial.md`
